# MiYooSDR 0.5.0

Play saved Wi-Fi packet captures on the Miyoo Mini Plus. The recording browser
now opens PCAPs alongside existing spectrum CSV recordings.

- Browse `.pcap` and `.csv` files from `App/MiYooSDR/rec/` and `research/` with
  SELECT + START. The capture script's `research/stock-monitor.pcap` appears here.
- Review a packet-count timeline, scrolling frame list, and selected-frame
  addresses, type, length, and available rate, signal and channel metadata.
- Pause / play with A, step packets with Left / Right, seek a second with Up /
  Down, and change speed from 0.25× to 8× with L1 / R1. Playback stops at the end;
  A restarts it. B returns to the browser, MENU quits, and START saves a screenshot.
- Open a PCAP directly with `launch.sh --replay FILE.pcap`, skipping radio setup
  and the launcher's Wi-Fi and audio teardown.
- Render a desktop screenshot with `--replay FILE.pcap --replay-at SECONDS
  --shot output.png`.

Supports classic PCAP with radiotap link type 127, either byte order, and
microsecond or nanosecond timestamps, with a limit of 100,000 records. PCAPNG is
not supported. Playback displays stored frame headers and metadata; it does not
decrypt protected payloads, reconstruct a waveform or spectrum, or transmit frames.
Known stock-driver rate and signal-reporting issues still apply.

Validated against the original 3,647-frame capture: the Miyoo's offline screenshot
matches the host rendering byte for byte, and Wi-Fi stayed connected. Automated
tests cover supported PCAP formats, malformed files, metadata limits, and offline
rendering and launch behavior.

## Install and play

Extract `miyoosdr-0.5.0.zip` to the root of the SD card. It installs under
`App/MiYooSDR`. Existing recordings and settings are not included in the archive.

Copy a compatible PCAP into `App/MiYooSDR/rec/` or `research/`, start MiYooSDR,
and press SELECT + START. Select the file with Up / Down and press A. Spectrum
CSV review remains available in the same browser.

To open an existing capture over SSH while keeping Wi-Fi connected:

```sh
cd /mnt/SDCARD/App/MiYooSDR
./launch.sh --replay research/stock-monitor.pcap
```

The command-line capture utility and its managed Wi-Fi recovery procedure remain
available in `research/`. Capture is separate from playback; see the
[driver research notes](../driver-research.md) for capture instructions and
metadata limitations. No kernel or driver replacement is included.
