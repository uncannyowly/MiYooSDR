# MiYooSDR 0.4.0

This release adds an experimental command-line Wi-Fi packet capture utility for
the Miyoo Mini Plus stock RTL8188FU driver. The spectrum application's controls
remain the same.

- Capture 802.11 frames with radiotap metadata into Wireshark-compatible PCAP.
- Run an eight-second capture with managed Wi-Fi restoration and a recovery timer.
- Inspect captures on a computer, including independent FCS checks.
- Includes driver research notes and known metadata limitations.
- Corrects the documentation on PSD timing and the unproven raw-I/Q capture path.

The original on-device test captured 3,647 frames, including 202 beacons, with all
frame checksums verified and zero socket drops. Wi-Fi recovered automatically.
The driver can report an incorrect legacy data rate and suspect signal values;
see the research notes before interpreting PHY metadata.

## Install

Extract `miyoosdr-0.4.0.zip` to the root of the SD card. It installs under
`App/MiYooSDR`. Existing recordings and settings are not included in the archive.

The capture utility lives in `App/MiYooSDR/research/`; it is separate from the
spectrum viewer. To start a capture over SSH, run:

```sh
nohup sh /mnt/SDCARD/App/MiYooSDR/research/monitor-capture.sh \
  > /mnt/SDCARD/App/MiYooSDR/research/monitor-capture.log 2>&1 < /dev/null &
```

SSH disconnects during capture. After Wi-Fi returns, retrieve
`App/MiYooSDR/research/stock-monitor.pcap`. Read
[`../driver-research.md`](../driver-research.md) for prerequisites, recovery,
and how to rearm subsequent experiments. Do not run capture alongside the viewer.

No kernel or driver replacement is included. Raw I/Q, Bluetooth packet decoding,
and Zigbee packet decoding remain unsupported.
